# Commercial Area Dataset 설명

## 1. 데이터 개요

이 데이터셋은 **서울 행정동 기준 상권 분석을 위한 데이터**입니다.

데이터 단위는 다음과 같습니다.

행정동 × 통합카테고리 × 분기

예시

| 분기 | 행정동 | 업종 |
|-----|------|------|
| 2020Q1 | 청운효자동 | 카페 |
| 2020Q1 | 청운효자동 | 미용실 |

즉 **특정 행정동에서 특정 업종의 상권 상태를 나타내는 데이터**입니다.

---

## 2. 데이터 출처

사용된 원본 데이터

1. 서울시 추정 매출 (행정동 기준) — 2019Q1 ~ 2025Q3
2. 서울시 유동인구 (행정동 기준) — 2019Q1 ~ 2025Q3
3. 서울 상가 정보 — 2020Q1 ~ 2025Q4

---

## 3. 업종 구조

서울시 데이터의 업종 분류를 **25개 통합 카테고리로 재구성**했습니다.

예시

| 원본 업종 | 통합카테고리 |
|------|------|
| 한식음식점 | 한식 |
| 커피-음료 | 카페 |
| 네일숍 | 뷰티/화장품 |

- Rows: 190,089 (dropna 후)

- 분기: 2020Q1 ~ 2025Q3 (23개 분기)

---

## 6. 모델링 목표

두 가지 방향의 추천을 제공합니다.

### 업종 추천 버튼 클릭 → 행정동 추천

입력: 업종명 (예: 카페)
출력: 해당 업종 창업에 적합한 행정동 TOP N 추천

### 행정동 클릭 → 업종 추천

입력: 행정동명 (예: 역삼1동)
출력: 해당 행정동에서 다음 분기 성장 가능성이 높은 업종 TOP 5

---

## 7. 모델 구조

### 문제 유형

Binary Classification — 다음 분기에 매출이 성장할지 여부 예측

### 정답(Label) 생성

```
당분기 매출 < 다음분기 매출 → 1 (성장)
당분기 매출 >= 다음분기 매출 → 0 (감소)
```

### Train / Test 분리 (Temporal Split)

시간 순서를 지켜 미래 데이터로 과거를 예측하는 상황을 방지합니다.

```
훈련: 2020Q1 ~ 2025Q1 (21개 분기, 173,201건)
테스트: 2025Q2 → 2025Q3 성장 여부 예측 (8,160건)
추천: 2025Q3 데이터 기준으로 다음 분기 성장 확률 계산
```

### 모델

RandomForestClassifier (n_estimators=300, class_weight="balanced")

### 모델 입력 Feature (13개)

| Feature | 중요도 | 설명 |
|---|---|---|
| 분기번호 | 8.9% | 계절성 (1~4분기) |
| 업종_점포당매출 | 8.4% | 점포당 평균 매출 |
| 업종_매출점유율 | 8.4% | 상권 내 업종 영향력 |
| 업종_포화도 | 8.3% | 시장 포화 정도 |
| MZ_차이 | 8.2% | MZ 소비 집중도 |
| 유동대비매출 | 7.9% | 유동인구 대비 매출 효율 |
| 유동_20대비율 | 7.8% | 20대 유동인구 비중 |
| 당월매출합 | 7.8% | 현재 업종 매출 규모 |
| 점포대비유동 | 7.8% | 점포당 잠재 고객 수 |
| 매출_20대비율 | 7.8% | 20대 소비 비중 |
| 총유동인구 | 7.6% | 지역 유동인구 규모 |
| 경쟁강도 | 5.9% | 동일 업종 점포 수 |
| 업종_encoded | 5.2% | 업종 종류 |

### 현재 성능

| 지표 | 이전 (3개 분기) | 현재 (23개 분기) |
|---|---|---|
| Accuracy | 48% | **58%** |
| AUC-ROC | 0.465 | **0.657** |
| 성장 Precision | 51% | **68%** |

AUC-ROC 기준으로 **0.465 → 0.657**, 랜덤 찍기(0.5) 수준에서 실질적인 예측력을 갖춘 수준으로 향상됐습니다.
