## 최우선 원칙

1. **속도 우선** — 설명보다 구현 먼저. 작동하는 결과를 만드는 것이 우선.
2. **복기 가능성 보장** — 작업 후에는 무엇을/왜/어디를 바꿨는지 정리.
3. **기존 구조 존중** — 불필요한 리팩토링 금지. 현재 흐름 유지.
4. **설명은 사후 정리** — 구현 중 장황한 설명 금지. 끝난 후 복습용 요약 제공.
